# Car Value — сервис оценки автомобилей

## О проекте

Лабораторная работа по дисциплине «Проектирование веб-сервисов».

Вариант №46 — Оценка авто (Car Value).

Car Value — веб-приложение для расчёта ориентировочной стоимости автомобиля по году выпуска и пробегу.

## Возможности

- Расчёт стоимости автомобиля.
- Определение диапазона стоимости.
- Учёт возраста и среднегодового пробега.
- Сохранение результатов в PostgreSQL.
- Просмотр истории оценок.
- Удаление отдельных записей.
- Очистка истории.
- Постраничная навигация.

## Технологии

- Frontend: HTML, CSS, JavaScript, Nginx.
- Backend: Python, FastAPI.
- Database: PostgreSQL 17.
- Web-service: Python, FastAPI.
- Контейнеризация: Docker Compose.

## Архитектура

Приложение состоит из четырёх контейнеров:

1. frontend — пользовательский интерфейс.
2. backend — REST API.
3. db — база данных PostgreSQL.
4. web-service — расчёт стоимости автомобиля.

Frontend → Backend → Web-service

Backend → PostgreSQL

## Запуск приложения

1. Установить Docker и Docker Compose.
2. Склонировать репозиторий.
3. Создать файл .env на основе .env.example.
4. Установить пароль PostgreSQL в POSTGRES_PASSWORD.
5. Выполнить команду:

    docker compose up --build -d

6. Открыть http://localhost:8080

## REST API

- POST /api/estimate — расчёт и сохранение оценки.
- GET /api/history — получение истории.
- GET /api/history/{id} — получение одной оценки.
- DELETE /api/history/{id} — удаление записи.
- DELETE /api/history — очистка истории.
- GET /api/health — проверка Backend.

## База данных

История оценок хранится в таблице valuation_history.

Первоначальная структура создаётся автоматически через db/init.sql.

Docker Volume обеспечивает сохранение информации после перезапуска контейнеров.

## Алгоритм оценки

Используется учебная математическая модель.

Стоимость рассчитывается по году выпуска и пробегу с учётом возрастной амортизации.

Базовая стоимость: 4 000 000 рублей.

Диапазон результата: ±7%.

Результат не является профессиональной рыночной оценкой автомобиля.

## Остановка

    docker compose down

Повторный запуск:

    docker compose up -d

Данные PostgreSQL сохраняются после перезапуска.
